# Product PRD

## Problem and Outcome

Describe the real user problem and the measurable product outcome.

## Users and Jobs

List user roles and the jobs they need to complete.

## Current State

Summarize current behavior, missing capability, and relevant constraints.

## Target Workflows

Describe production workflows end to end.

## Domain Objects and States

List domain objects, allowed states, transitions, and ownership.

## Scope

List included behavior for this release candidate.

## Non-goals

List explicitly excluded behavior.

## Acceptance Items

Use stable IDs such as `AC-001`; every item must be observable.

## Privacy and Security

Describe data minimization, redaction, authentication, authorization, and upload limits.

## Open Questions

Use `None` only when no product-blocking questions remain.
